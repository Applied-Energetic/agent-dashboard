# Agent Dashboard 扁平玻璃视觉设计

## 目标

将当前偏传统后台的灰色卡片界面调整为适合 Obsidian 桌面浅色模式的克制型扁平玻璃界面。保留现有信息架构、功能逻辑和高信息密度，不引入新依赖，也不读取或修改额外 Vault 数据。

## 视觉方向

- 页面背景使用 Obsidian 主题变量，并叠加两处低对比度环境色晕，为透明面板提供可感知但不喧宾夺主的背景。
- 卡片使用低透明度背景、约 12px 的 `backdrop-filter` 模糊、细描边和极弱内高光。
- 移除卡片投影、按钮上浮、彩色底边和三种状态卡片的彩色左边框。
- 交互与状态统一使用 Obsidian 的 `interactive-accent`，错误、警告、成功仍使用对应语义色。
- 圆角保持克制，使用 Obsidian 的小号或中号圆角变量，不采用胶囊式大圆角。
- 保留现有等宽数据标签和高密度网格，标题继续承担主要视觉层级。

## 信息布局

- 不改变 Header、快捷操作、状态卡片、热力图、周期复盘、今日任务和外部信息流的排列关系。
- 热力图与周期复盘仍为宽屏双栏；窄屏仍上下排列。
- 状态卡片、快捷操作和列表行改为平面层级，通过透明度、描边和间距区分，不依赖阴影。
- 热力图格子保留清晰对比，避免透明化影响数据可读性。

## 中文化

可面向用户理解的界面文案尽量改为中文，包括：

- 顶部状态、同步、刷新和更新时间。
- 快捷操作名称及其动作提示。
- Vault 状态、路径提示、评分说明和空状态。
- 热力图、周期复盘、今日任务、外部信息流标题及状态标签。
- 周、月、季度、年度复盘入口名称。

保留 GitHub、RSS、Codex、Claude、Agent Dashboard、文件路径、仓库名称、周期目标值以及必要技术缩写。

## 交互与无障碍

- 所有按钮继续使用原生 `button`，保持键盘操作和现有 ARIA 标签。
- hover 只改变透明度、描边和轻微底色，不产生位移。
- `focus-visible` 使用清晰的强调色轮廓。
- 交互行最小高度不低于 44px。
- 遵循 `prefers-reduced-motion`。
- `backdrop-filter` 不可用时，半透明背景仍应保证文字可读。

## 实施范围

- 主要修改 `styles.css` 的颜色令牌、面板、按钮、卡片、列表行和响应式样式。
- 修改 `src/views/AgentDashboardView.ts` 及相关用户界面字符串以完成中文化。
- 必要时修改其他包含界面提示的 TypeScript 文件，但不改变功能流程。
- 版本升级为 `0.1.3`，发布日期保持 `2026-07-30`，同步 manifest、package、lockfile、versions、CHANGELOG、AGENTS 和 CLAUDE。

## 验证与发布

- 运行 `npm test`、`npm run build`、`npm run lint`。
- 检查版本字段一致、AGENTS 与 CLAUDE 内容一致。
- 验证后仅复制 `main.js`、`manifest.json`、`styles.css` 到当前打开的 `Blog_backup` 插件目录并校验哈希。
- 不执行 Git commit 或 push。
